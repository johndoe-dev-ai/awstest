ठीक है — नीचे मैं एक ready-to-use Gradle (Java 21) प्रोजेक्ट का skeleton और कोड दे रहा हूँ जो आपकी स्क्रीन पर दिख रहे requirement को पूरा करता है:

JDBC से data fetch करेगा (businessDate के हिसाब से)

JSON में convert करेगा (Jackson)

Kafka topic पर publish करेगा (kafka-clients)

Kerberos-based authentication को config से सपोर्ट करेगा (JAAS/krb5.cfg placeholders)

Java 21 और Gradle प्रोजेक्ट structure के अनुरूप है

फाइलें आपकी दिखायी directory structure com.barclays.datalens में रखी गयी हैं


मैंने गैर-निर्दिष्ट DB/driver (e.g., Hive/Impala/Presto/Postgres) को generic रखा है—आप JDBC ड्राइवर और JDBC URL को अपनी environment के हिसाब से बदल देंगे। नीचे सब कुछ copy-paste करने के लिए है।

4) Java code — structure: src/main/java/com/barclays/datalens/...

4a) LambdaApplication.java — entry point

src/main/java/com/barclays/datalens/LambdaApplication.java

package com.barclays.datalens;

import com.barclays.datalens.service.DataFetcherService;
import com.barclays.datalens.service.KafkaPublisherService;
import java.time.LocalDate;
import java.util.List;
import java.util.Map;
import java.util.Properties;

public class LambdaApplication {
    public static void main(String[] args) throws Exception {
        // Load properties (simple)
        Properties props = new Properties();
        try (var in = LambdaApplication.class.getResourceAsStream("/application-nonprod.properties")) {
            if (in != null) props.load(in);
        }

        String businessDate = args.length > 0 ? args[0] : LocalDate.now().toString(); // YYYY-MM-DD

        DataFetcherService fetcher = new DataFetcherService(props);
        List<Map<String, Object>> rows = fetcher.fetchByBusinessDate(businessDate);

        KafkaPublisherService publisher = new KafkaPublisherService(props);
        int published = 0;
        for (Map<String, Object> row : rows) {
            publisher.publishAsJson(row);
            published++;
        }

        System.out.println("Published " + published + " messages to Kafka for businessDate=" + businessDate);
        publisher.close();
        fetcher.close();
    }
}

4b) DataFetcherService.java

src/main/java/com/barclays/datalens/service/DataFetcherService.java

package com.barclays.datalens.service;

import com.fasterxml.jackson.databind.ObjectMapper;

import java.sql.*;
import java.util.*;

public class DataFetcherService implements AutoCloseable {
    private final Connection conn;
    private final String query;

    public DataFetcherService(Properties props) throws Exception {
        String driver = props.getProperty("jdbc.driver");
        String url = props.getProperty("jdbc.url");
        String user = props.getProperty("jdbc.user");
        String password = props.getProperty("jdbc.password", "");

        // load driver
        Class.forName(driver);

        // If Kerberos is used, ensure JVM was started with JAAS and krb5 config. Connection may rely on driver-specific props.
        this.conn = DriverManager.getConnection(url, user, password);
        this.query = props.getProperty("jdbc.query");
    }

    public List<Map<String, Object>> fetchByBusinessDate(String businessDate) throws SQLException {
        try (PreparedStatement ps = conn.prepareStatement(query)) {
            ps.setString(1, businessDate);
            try (ResultSet rs = ps.executeQuery()) {
                return resultSetToList(rs);
            }
        }
    }

    private List<Map<String, Object>> resultSetToList(ResultSet rs) throws SQLException {
        List<Map<String, Object>> rows = new ArrayList<>();
        ResultSetMetaData md = rs.getMetaData();
        int cols = md.getColumnCount();
        while (rs.next()) {
            Map<String, Object> row = new LinkedHashMap<>();
            for (int i = 1; i <= cols; i++) {
                String colName = md.getColumnLabel(i);
                Object val = rs.getObject(i);
                row.put(colName, val);
            }
            rows.add(row);
        }
        return rows;
    }

    @Override
    public void close() throws Exception {
        if (conn != null && !conn.isClosed()) conn.close();
    }
}

4c) KafkaPublisherService.java

src/main/java/com/barclays/datalens/service/KafkaPublisherService.java

package com.barclays.datalens.service;

import com.fasterxml.jackson.databind.ObjectMapper;
import org.apache.kafka.clients.producer.*;

import java.util.Map;
import java.util.Properties;
import java.util.concurrent.Future;

public class KafkaPublisherService {
    private final Producer<String, String> producer;
    private final String topic;
    private final ObjectMapper mapper = new ObjectMapper();

    public KafkaPublisherService(Properties props) {
        Properties p = new Properties();
        p.put(ProducerConfig.BOOTSTRAP_SERVERS_CONFIG, props.getProperty("kafka.bootstrap.servers"));
        p.put(ProducerConfig.KEY_SERIALIZER_CLASS_CONFIG, "org.apache.kafka.common.serialization.StringSerializer");
        p.put(ProducerConfig.VALUE_SERIALIZER_CLASS_CONFIG, "org.apache.kafka.common.serialization.StringSerializer");

        // If SASL/Kerberos is used for Kafka, additional configs are required:
        // p.put("security.protocol", "SASL_PLAINTEXT");
        // p.put("sasl.kerberos.service.name", "kafka");
        // JVM should be started with JAAS (java.security.auth.login.config)

        this.producer = new KafkaProducer<>(p);
        this.topic = props.getProperty("kafka.topic");
    }

    public Future<RecordMetadata> publishAsJson(Map<String, Object> row) throws Exception {
        String value = mapper.writeValueAsString(row);
        ProducerRecord<String, String> record = new ProducerRecord<>(topic, null, value);
        return producer.send(record);
    }

    public void close() {
        if (producer != null) producer.close();
    }
}

5) Kerberos / Kafka / JDBC notes (important)

1. Kerberos for JDBC: कई JDBC ड्राइवर (खासकर Hive/Impala) Kerberos authentication support करते हैं। आपका JDBC URL और driver-specific properties (principal, authenticaiton, useSasl, आदि) बदलने होंगे। उदाहरण: Hive में jdbc:hive2://host:10000/default;principal=hive/_HOST@REALM.


2. JAAS & krb5.conf:

jaas.conf में principal और keytab path दें। JVM को यह path -Djava.security.auth.login.config=/path/to/jaas.conf से बताएं।

Kerberos realm/config के लिए -Djava.security.krb5.conf=/etc/krb5.conf दे सकते हैं या system-level पर रखें।



3. Kafka with Kerberos (SASL/GSSAPI):

Kafka client के लिए producer config में security.protocol=SASL_PLAINTEXT (या SASL_SSL) और sasl.kerberos.service.name=kafka जैसे props चाहिए। JAAS config भी जरूरी होगा।

Example:

security.protocol=SASL_PLAINTEXT
sasl.kerberos.service.name=kafka

JAAS entry नाम KafkaClient हो सकता है। अगर Kafka cluster Kerberos use करता है तो jaas.conf में Kafka client entry भी रखें:

KafkaClient {
  com.sun.security.auth.module.Krb5LoginModule required
  useKeyTab=true
  keyTab="/path/to/your.keytab"
  principal="client_principal@YOUR.REALM";
};



4. Permissions: Ensure the process can read the keytab and krb5.conf, and host principal/keytab are valid.

8) Quick checklist for you to provide / configure

किस DB का JDBC driver/libraries इस्तेमाल करना है? (Hive/Impala/Postgres/Oracle आदि) — मैं dependency और jdbc.url को उसी के अनुरूप adjust कर दूँगा।

Kafka cluster के लिए क्या Kerberos/SASL enabled है? अगर हाँ, तो मैं jaas.conf में KafkaClient entry और producer configs जोड़ दूंगा।

Keytab path और principal (या आप चाहें तो local testing के लिए non-Kerberos credentials भी दिखा दूँ)।

आप चाहें तो मैं यह code सीधे आपके repo के लिए एक complete Gradle project के रूप में तैयार कर दूँ — या मैं driver-specific adjustments कर दूँ।
